# Sepsis AI Model

Machine learning project for early sepsis prediction
using patient-level ICU time-series data.

## Project Status

Currently:
- Dataset inspection completed
- Dataset A and B analyzed
- Sepsis timing analysis completed
- Prediction target under development

## Dataset

Dataset A: 20,336 patient files
Dataset B: 20,000 patient files

Total: 40,336 patients

Raw dataset files are not included in this repository.
